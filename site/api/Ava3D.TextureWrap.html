TextureWrap

public enum TextureWrap

How a texture behaves outside 0..1.

Values

Value
Repeat

Tiles the image. The glTF default.

ClampToEdge

Holds the edge pixel, so coordinates past the edge smear rather than tile.

MirroredRepeat

Tiles, flipping every other repetition so tiles meet seamlessly.
