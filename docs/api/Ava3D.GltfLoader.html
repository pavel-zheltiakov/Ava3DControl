Documentation · Loading glTF

GltfLoader

public static class GltfLoader

Loads binary glTF (.glb) into an Ava3D scene.

SharpGLTF is fully managed, which is the whole reason it is usable here — Assimp, the usual choice for CAD formats, is a native library and cannot load under WebAssembly at all. Choosing a managed loader is not a preference; it is the difference between having a browser build and not.

Node transforms are kept per node rather than baked into vertices, so a CAD assembly stays one draw call per part and identical geometry can share a Mesh.

Only binary glTF is read. A multi-file .gltf would need every satellite file fetched through a URI resolver, which the browser makes awkward; pack it to a .glb first.
