EnvironmentLight

public sealed class EnvironmentLight

The light that comes from everywhere: a two-colour hemisphere, sky above and ground below.

A metallic-roughness renderer needs this to be honest. A metal has no diffuse response at all — it is only what it reflects — so with a single key light a metal sphere is a black ball with one hot spot on it. Something has to fill the rest of the reflection, and this is the cheapest thing that can: evaluated analytically from the reflection vector, no cubemap, no prefiltering, no assets, and identical arithmetic on all three backends.

It is not image-based lighting and does not pretend to be — a mirror reflects a smooth gradient rather than a room. What it does buy is the thing that matters for a viewer control: roughness reads correctly, metals look like metal, and the whole model works on a phone.

Properties

Vector3 GroundColor { get; set; }

Linear RGB seen by surfaces facing down. The default is dim warm ground bounce.

float Intensity { get; set; }

Overall multiplier, 0 to switch the environment off entirely. Clamped to 0..8.

static EnvironmentLight None { get; }

An environment that contributes nothing, for scenes that want the key light alone.

Vector3 SkyColor { get; set; }

Linear RGB seen by surfaces facing up. The default is a cool overcast sky.

Methods

A neutral grey studio environment of the given brightness.
